BOLETÍN «LO QUE HAY QUE SABER» · PATRIAM
Diseño y desarrollo web: odlc.es
=========================================

CÓMO FUNCIONA
-------------
- Todo se gestiona desde el editor de la web (enlace «Acceso editor» en el pie del boletín).
  No hay que descargar ni subir archivos: lo que se escribe se guarda solo en la web.
- Los datos (boletines, biblioteca, «Al momento», fotos) y los usuarios se guardan en Netlify (Netlify Blobs).
  Las contraseñas se guardan cifradas y nunca aparecen en la web ni en GitHub.
- Los usuarios preparan y envían a aprobación. Los administradores (Carlos y PATRIAM) aprueban y publican:
  al pulsar «Aprobar y publicar» ya está en la web.
- En el editor, el botón «? Instrucciones» explica paso a paso cómo se hace cada cosa.

GITHUB Y NETLIFY (solo para quien mantiene la web)
--------------------------------------------------
- El código está en GitHub (repositorio patriam-boletin) y Netlify lo publica solo al guardar cambios allí.
- Cambiar archivos en GitHub NO borra los boletines, las fotos ni los usuarios: esos están guardados en Netlify, aparte.
  Los archivos netlify/datos/semilla.mjs y usuarios-semilla.mjs solo se usan la primera vez, cuando Netlify aún no tiene nada guardado.
- boletines.js es solo una copia de seguridad para abrir la web en local. En la web publicada no se usa.
- Configuración de Netlify: Build command vacío, Publish directory «.». No hace falta nada más.
